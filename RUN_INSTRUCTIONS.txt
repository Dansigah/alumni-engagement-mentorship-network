ALUMNI ENGAGEMENT AND MENTORSHIP NETWORK - RUN INSTRUCTIONS

Requirements
- Java 21
- MySQL 8
- Node.js and npm

Database
- Database name: alumni_mentorship_db
- MySQL must be running before Spring Boot is started.
- Create the database if it does not already exist:
  CREATE DATABASE alumni_mentorship_db;

Backend (Windows PowerShell)
1. Open PowerShell in the backend folder.
2. If Java is not already configured, set JAVA_HOME to your Java 21 installation.
3. Set the required environment variables for the current PowerShell window:
   $env:SPRING_DATASOURCE_PASSWORD="<your_mysql_root_password>"
   $env:JWT_SECRET="<your_jwt_secret>"

   Placeholder reference:
   DB_PASSWORD=<your_mysql_root_password>
   JWT_SECRET=<your_jwt_secret>

4. Start the backend:
   .\mvnw.cmd spring-boot:run

Backend URL: http://localhost:8080
Swagger URL: http://localhost:8080/swagger-ui/index.html

Frontend
1. Open a terminal in the frontend folder.
2. Install dependencies:
   npm install
3. Start the development server:
   npm run dev

Frontend URL: http://localhost:5173

Notes
- Keep both backend and frontend terminals running while using the application.
- Do not commit real database passwords or JWT secrets to project files.
